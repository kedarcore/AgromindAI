# 🌱 AgromindAI – Smart Crop Advisor

AgromindAI is a smart farming project that helps farmers decide which crops may be suitable for their land. It considers details like soil type, weather conditions, rainfall, location, water availability, and budget to provide crop-related suggestions.

The main aim of this project is to make crop selection easier and help farmers make better decisions before starting a new growing season.

## Features

- **Soil and Climate:** Enter soil type, season, location, temperature, and rainfall.
- **Crop Selection:** Select a crop based on your farming needs.
- **Farmer Profile:** Add your farming experience and investment budget.
- **Land Details:** Enter your land size and irrigation source.
- **Crop Advisory:** Get farming suggestions based on the information you provide.
- **Marathi Language:** Supports Marathi to make the application more accessible to local farmers.
- **History:** Check previous recommendations, if available in the application.

## Why I Built This Project

Choosing the right crop is not always easy. Farmers need to consider many things, including soil quality, rainfall, water availability, and the cost of cultivation.

I wanted to build a simple platform that brings these details together and helps farmers explore suitable crop options in one place.
